# Open Algebra KR 편집 지침

이 문서는 교재 전체에서 설명 방식, 수학 표기, 용어, 문제 구성과 검수 절차를 일관되게 유지하기 위한 기준이다.

## 1. 독자와 난이도

- 주 독자는 현대대수학을 처음 배우는 학부생과 독학자다.
- 정의와 정리의 엄밀성은 수학과 학부 교재 수준을 유지한다.
- 설명은 선형대수 기초와 집합·함수에 익숙한 독자가 따라갈 수 있게 쓴다.
- 뒤에서 배울 개념을 사용할 때에는 “예고”임을 명시하고, 현재 장의 증명에 몰래 사용하지 않는다.

## 2. 절의 기본 구조

가능하면 다음 순서를 따른다.

1. 학습 목표
2. 문제의 동기
3. 핵심 아이디어 또는 구체적 예제
4. 정의
5. 정리와 증명 전략
6. 완전한 증명
7. 반례 또는 자주 하는 실수
8. 이해 점검
9. 연습문제
10. 선별 풀이와 장 요약

정의 직후에는 최소 한 개의 예제 또는 비예제를 둔다. 증명의 핵심 발상이 바로 보이지 않을 때에는 `proofidea` 상자를 먼저 둔다.

## 3. 수학적 문장

- 명제의 가정과 결론을 한 문장 안에서 분명히 구분한다.
- “자명하다”, “쉽다”는 표현은 실제 논증을 생략해도 독자가 복원할 수 있을 때만 사용한다.
- 소거법칙, 가환성, 유한성, 정역성, 단위원 조건을 사용한 위치를 드러낸다.
- 몫구조와 대입 사상에서는 잘 정의성을 반드시 확인한다.
- 동형은 가능한 한 구체적인 사상과 그 핵·상 또는 역함수를 함께 제시한다.
- 반례가 있는 역명제는 역이 거짓임을 명시하고 대표 반례를 든다.

## 4. 표준 용어

본문의 기본 용어는 다음을 사용한다.

| 한국어 | 영어 | 비고 |
|---|---|---|
| 준동형 | homomorphism | “호모모피즘”을 본문 용어로 쓰지 않음 |
| 동형 | isomorphism | |
| 자동동형 | automorphism | |
| 잉여류 | coset / residue class | 군에서는 coset, 환에서는 residue class |
| 정규부분군 | normal subgroup | |
| 아이디얼 | ideal | “이상”을 사용하지 않음 |
| 단위원 | unit | |
| 영인수 | zero divisor | |
| 멱영원소 | nilpotent element | |
| 정역 | integral domain | |
| 주아이디얼정역 | principal ideal domain | PID 병기 가능 |
| 유일인수분해정역 | unique factorization domain | UFD 병기 가능 |
| 일계수다항식 | monic polynomial | |
| 원시다항식 | primitive polynomial | |
| 내용 | content | `cont(f)` |
| 분해체 | splitting field | |
| 근호로 풀림 | solvable by radicals | |

“5차방정식”을 사용하고, 의미가 모호한 “오차방정식”은 사용하지 않는다.

## 5. 기호

- 수의 체는 `\Z`, `\Q`, `\R`, `\C`, `\F` 매크로를 사용한다.
- 군의 부분군은 `H\le G`, 정규부분군은 `N\trianglelefteq G`로 쓴다.
- 환의 아이디얼은 문맥이 명확하면 `I\trianglelefteq R`를 사용할 수 있지만, 군의 정규성과 혼동될 때에는 “아이디얼”을 문장으로 쓴다.
- 상은 `\im\varphi`, 핵은 `\ker\varphi`로 쓴다.
- 동형은 `\cong`, 정의에 의한 등식은 필요한 경우 `:=`를 사용한다.
- 다항식 변수는 대문자 `X,Y`, 값을 대입한 원소는 소문자 또는 그리스 문자 `x,\alpha`를 사용한다.
- 최대공약수는 체 위 다항식에서 일계수로 정규화한다.
- 영다항식의 차수는 `-\infty`로 둔다.

## 6. 정리와 증명

- 정의·정리·명제·보조정리·따름정리는 장별 연속 번호를 사용한다.
- `proofidea`는 증명의 논리 구조만 설명하고, 계산의 세부를 완전한 증명에 둔다.
- 같은 정리를 뒤에서 사용할 때에는 가능한 한 절 이름이나 정리 이름을 함께 적는다.
- 정리의 일반성보다 학습의 명확성이 중요한 경우, 먼저 체나 가환환의 표준 경우를 증명하고 일반화의 범위를 설명한다.

## 7. 연습문제

- A: 정의 확인과 직접 계산
- B: 핵심 정리의 재증명과 표준 논증
- C: 여러 절을 연결하는 구조·응용 문제

별표 문제는 다음 중 하나를 만족해야 한다.

- 장의 핵심 정리를 대표한다.
- 뒤 장에서 직접 사용한다.
- 중요한 반례나 표준 계산을 제공한다.

선별 풀이에서는 최종 답만 적지 않고, 사용한 정리와 핵심 선택을 설명한다. 문제의 가정과 풀이의 가정이 정확히 일치해야 한다.

## 8. 인용과 독창성

- 특정 교재의 문장을 번역하거나 문단 구조를 그대로 옮기지 않는다.
- 표준 정의와 정리는 출처 독점 대상이 아니지만, 역사적 주장과 특수한 관점은 참고문헌을 표시한다.
- 외부 문제를 변형하여 사용할 때에는 출처와 라이선스를 확인한다.
- AI 도구의 제안은 반드시 수학적으로 재검산하고, 검수 기록을 남긴다.

## 9. Git과 검수

- 기능 또는 검수 단위로 브랜치를 만든다.
- 수학적 수정은 `qa:` 또는 `fix:` 커밋으로 남긴다.
- PR에는 수정한 가정, 반례, 계산과 빌드 결과를 적는다.
- 병합 전 Volume 1 전체 XeLaTeX 빌드를 성공시킨다.
- 장별 1차 수학 검수, 전체 표기 검수, 조판 검수, 외부 독자 검토를 구분하여 기록한다.
