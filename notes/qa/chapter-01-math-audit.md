## 수정한 수학적 사항

### 1. 제3동형정리의 가정

기존 진술은

```text
N ◁ H ◁ G
```

만을 가정했다. 정규성은 일반적으로 추이적이지 않으므로 이 조건만으로는 `G/N`을 만들 수 없다. 다음과 같이 수정했다.

```text
N ◁ G, H ◁ G, N ⊆ H
```

또한 `N ◁ H`와 `H ◁ G`이지만 `N`이 `G`에서 정규가 아닌 반례로

```text
N = <(12)(34)> ◁ V4 ◁ A4
```

를 추가했다.

### 2. 부호 준동형의 경계 조건

`sgn : S_n → {±1}`이 전사라는 설명에 `n ≥ 2`를 명시했다. `n=1`에서는 부호 준동형의 상이 자명군이기 때문이다.

### 3. 직접곱 원소의 위수

순환군 직접곱 명제에서 사용한

```text
ord(a,b) = lcm(ord(a), ord(b))
```

을 본문 안에서 직접 증명하도록 보강했다. 이후 연습문제의 결론을 앞서 암묵적으로 사용하는 순환을 제거했다.

### 4. 심화 문제의 가정과 결론

- 중국인의 나머지 정리 문제에 `m,n`이 양의 정수임을 명시했다.
- `|G/N|=p^2` 문제의 결론을 `N ⊊ H ⊊ G`인 중간부분군의 존재로 명확히 했다.
- 같은 문제에 현재 장의 도구만으로 풀 수 있는 힌트를 추가했다.

### 5. 풀이의 완결성과 문장

- `(Z/15Z)^×`의 모든 역원을 빠짐없이 명시했다.
- 중국인의 나머지 정리 풀이에 남아 있던 영문 표현을 한국어로 수정했다.
