## 3. 주요 검수·수정 사항

### 3.1 분리다항식의 계산 판정

다음 동치를 중복도 계산에서 직접 증명했다.

```text
α가 f의 중근
⇔ f(α)=f'(α)=0
```

그 결과

```text
f가 분리다항식 ⇔ gcd(f,f')=1
```

을 얻었다. 기약다항식에 대해서는 `f`가 분리일 필요충분조건이 `f' != 0`임을 별도로 분리해 서술했다.

### 3.2 양의 표수의 중복도 구조

`f'=0`과 `f(X)=g(X^p)`의 동치를 증명하고, 일계수 기약다항식에 대해 최대의 `r`을 택하여

```text
f(X)=g(X^{p^r})
```

로 쓰면 `g`가 기약인 분리다항식이며 모든 근이 공통 중복도 `p^r`을 갖는다는 정리를 완전하게 전개했다.

### 3.3 분리차수의 정의와 곱셈공식

유한 대수적 확장에 대해

```text
[L:K]_s = # Hom_K(L, Kbar)
```

로 분리차수를 정의하고, 단순확장에서는 최소다항식의 서로 다른 근의 수와 일치함을 확인했다. 확장탑에서는 제한 사상의 각 섬유가 같은 크기를 갖도록 매장 연장 정리를 적용하여

```text
[M:K]_s = [M:L]_s [L:K]_s
```

를 증명했다.

### 3.4 원시원 정리

- 유한 기준체의 경우 유한체 곱셈군의 순환성을 사용했다.
- 무한 기준체의 경우 서로 다른 매장의 상을 충돌시키는 유한개의 계수만 제외하고 `α+cβ`를 택하는 표준 논증을 사용했다.
- 분리성 가정이 빠지면 성립하지 않는 반례로 `F_p(s,t)/F_p(s^p,t^p)`를 제시했다.

### 3.5 완전체와 프로베니우스

표수 `p>0`에서 다음 동치를 양방향으로 증명했다.

```text
K가 완전체
⇔ Frobenius a ↦ a^p 가 전사
⇔ 모든 a∈K가 K 안에서 p제곱근을 가짐
```

유한체가 완전체라는 결론과 완전체의 대수적 확장도 완전체라는 명제까지 연결했다.

### 3.6 순수비분리 확장과 분리폐포

순수비분리 확장에 대해 다음 조건들의 동치를 확인했다.

```text
모든 원소가 순수비분리적
⇔ 각 α에 대해 α^{p^r}∈K인 r가 존재
⇔ K를 고정하는 대수적 폐포로의 매장이 하나뿐
```

또한

```text
K_s = {α∈L : α가 K 위에서 분리적}
```

가 중간체이고 `K_s/K`는 분리, `L/K_s`는 순수비분리이며 이 조건을 만족하는 중간체가 유일함을 증명했다.

### 3.7 조판 수정

- 분리차수 절과 원시원 절이 앞 절의 마지막 상자와 붙지 않도록 절 시작을 조정했다.
- 복습 카드 목록의 잘못된 선택 인자 사용을 제거했다.
- 대수적 폐포 자동동형 표기를 완전한 LaTeX 수식으로 교정했다.
- 최종 빌드에서 `tcolorbox`, 참조, 북마크와 overfull 관련 원고 경고가 남지 않음을 확인했다.

## 4. 독립 재계산 결과

### 4.1 분리다항식 예제

```text
X^4+X^2+1 = (X^2+X+1)^2  in F_2[X]
```

이므로 서로 다른 근은 두 개이고 각각의 중복도는 `2`이다.

```text
(X^6-X)' = -1 = 2  in F_3[X]
```

이므로 `X^6-X`는 분리다항식이다.

### 4.2 순수비분리 단순확장

`K=F_p(t^p)`, `L=F_p(t)`에 대해

```text
[L:K]=p,
[L:K]_s=1,
[L:K]_i=p.
```

이며 `X^p-t^p=(X-t)^p`임을 확인했다.

### 4.3 두 제곱근의 원시원

`θ=√2+√3`에 대해

```text
Q(θ)=Q(√2,√3),
θ^4-10θ^2+1=0.
```

확장차수가 `4`이므로 최소다항식은 `X^4-10X^2+1`이다.

### 4.4 두 변수 순수비분리 확장

```text
K=F_p(s^p,t^p),
L=F_p(s,t)
```

에 대해

```text
{ s^i t^j : 0≤i,j<p }
```

가 `L/K`의 기저이며

```text
[L:K]=p^2,
[L:K]_s=1,
[L:K]_i=p^2.
```

모든 `γ∈L`에 대해 `γ^p∈K`이므로 한 원소 생성 부분확장의 차수는 `p` 이하이고, 따라서 `L/K`는 단순확장이 아니다.

### 4.5 혼합 확장

`p`가 홀수이고

```text
K=F_p(s,t),
α^p=s,
β^2=t,
L=K(α,β)
```

일 때

```text
[L:K]=2p,
[L:K]_s=2,
[L:K]_i=p,
K_s=K(β).
```

를 탑 법칙과 분리-순수비분리 분해의 유일성으로 확인했다.
