## 1. 원자료와 학습용 보강의 구분

주요 원자료는 Siegfried Bosch, *Algebra: From the Viewpoint of Galois Theory*이다.

### 원자료의 직접적인 기반

다음 전개는 Bosch Sections 4.3, 5.4, 6.1을 직접적인 구조 기준으로 삼았다.

- 독립인 근들에 대한 대칭군 작용과 기본대칭식
- 대칭 유리함수의 고정체와 일반다항식의 갈루아군 `S_n`
- `[S_n,S_n]=A_n` 및 `[A_n,A_n]=A_n` (`n >= 5`)
- `S_n`이 `n >= 5`에서 가해군이 아니라는 사실
- 분리방정식이 근호로 풀릴 필요충분조건과 갈루아군의 가해성
- 일반 `n`차방정식이 `n >= 5`에서 근호로 풀리지 않는다는 결론
- 루피니·아벨·갈루아로 이어지는 역사적 맥락

## 3. 독립 재계산과 증명 확인

### 3.1 `A_5`의 원소와 켤레류

`S_5`를 직접 열거하여 다음을 확인했다.

```text
|A_5| = 60
identity             1
3-cycles            20
double transpositions 15
5-cycles            24
conjugacy class sizes: 1, 12, 12, 15, 20
```

항등원을 포함하는 켤레류 합의 가능한 크기는

```text
1, 13, 16, 21, 25, 28, 33, 36, 40, 45, 48, 60
```

이며, 이 가운데 `60`의 약수는 `1`과 `60`뿐임을 확인했다.

Sylow 부분군 개수도 독립 계산했다.

```text
n_2 = 5,  n_3 = 10,  n_5 = 6
```

### 3.2 `A_n` 단순성 증명의 교환자

원고의 순열 합성 convention에 따라 다음 항등식을 직접 검산했다.

```text
[(a b c), (a b c d ...)] = (a b d)
[(a b d), sigma] = (a b e c d),  e=sigma(d)
[(a b e), (a b)(c d)] = (a e b)
[(a c e), (a b)(c d)(e f)...] = (a c e)(b f d)
[(a b d), (a c e)] = (a b c)
```

고정점이 없는 전치곱의 경우 짝순열 조건 때문에 전치가 적어도 네 개 필요하다는 점도 확인했다.

### 3.3 도함부분군

직접 군 연산으로 다음을 재확인했다.

```text
D_5' = C_5
F_20' = C_5
A_5' = A_5
S_5' = A_5
```

따라서 `C_5,D_5,F_20`은 가해이고 `A_5,S_5`는 비가해라는 판정표와 일치한다.

### 3.4 일반다항식

고정체 증명의 차수 비교를 다음과 같이 점검했다.

```text
[L : L^{S_n}] = n!
L is the splitting field of product(X-T_i)
[L : k(s_1,...,s_n)] <= n!
k(s_1,...,s_n) subset L^{S_n}
```

중간체 차수 공식에서 반대 부등식이 나오므로 두 체가 같고, `L/k(s_1,...,s_n)`이 대수적이라는 사실에서 기본대칭식의 대수적 독립성이 따른다. 계수변수 `C_j -> (-1)^j s_j`의 체동형으로 일반다항식의 갈루아군이 `S_n`임을 다시 확인했다.

### 3.5 아벨--루피니 정리

증명의 의존관계를 다음 순서로 재검토했다.

```text
generic polynomial has Galois group S_n
n >= 5 implies S_n' = A_n and A_n' = A_n
therefore S_n is not solvable
solvable by radicals iff the Galois group is solvable
therefore no universal radical formula exists for n >= 5
```

개별 오차식 `X^5-2`는 가해군을 가지므로 근호로 풀린다는 반례를 함께 두어, 정리가 모든 오차식의 비가해성을 주장하지 않음을 확인했다.
