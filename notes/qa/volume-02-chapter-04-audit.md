## 3. 주요 검수·수정 사항

### 3.1 PDF 북마크 경고 제거

수식이 들어 있던 절 제목을 일반 문장형 제목으로 바꾸어 PDF 문자열 변환 경고를 제거했다. 최종 XeLaTeX 패스에는 원고 관련 경고가 남지 않는다.

### 3.2 정규성의 선행 사용 방지

정규확장의 정식 정의는 다음 장에 배치되어 있으므로, 유한체 위 대수적 확장에 관한 정리를 다음 두 성질로 먼저 서술했다.

```text
L/F_q는 분리확장이다.
F_q[X]의 기약다항식이 L 안에 한 근을 가지면 L에서 완전히 분해된다.
```

후자의 성질을 다음 장에서 정규성이라 부른다고 명시하여 장 순서의 논리적 의존성을 정리했다.

### 3.3 자동동형의 개수 논증 보강

정규성의 일반 정리를 미리 사용하지 않고 다음 순서로 증명했다.

1. 분리성으로 `F_q`-매장이 정확히 `n`개임을 계산한다.
2. 각 매장의 상은 원소가 `q^n`개인 대수적 폐포의 부분체이다.
3. 한 대수적 폐포 안에서 원소가 `q^n`개인 부분체는 하나뿐이다.
4. 따라서 모든 매장은 `F_{q^n}`의 자기동형이다.
5. 상대 프로베니우스의 `n`개 거듭제곱이 자동동형 전체이다.

### 3.4 프로베니우스 궤도 증명 보강

`alpha`의 궤도 길이를 `d`, 최소다항식 차수를 `e`라 할 때

```text
F_q(alpha)=F_{q^e} ⊂ F_{q^d}  ⇒ e|d,
alpha^(q^e)=alpha              ⇒ d|e
```

를 함께 사용하여 `d=e`를 엄밀히 증명했다.

### 3.5 모든 차수의 기약다항식 존재

`F_{q^n}^×`의 생성원은 어떤 진부분체에도 들어갈 수 없으므로 `F_q` 위 최소다항식 차수가 정확히 `n`이라는 직접 증명을 추가했다.

## 4. 독립 재계산 결과

### 4.1 작은 유한체

`F_4=F_2(alpha)`, `alpha^2+alpha+1=0`에서

```text
alpha^2=alpha+1,
alpha^3=1.
```

`F_8=F_2(alpha)`, `alpha^3+alpha+1=0`에서

```text
alpha^3=alpha+1,
alpha^4=alpha^2+alpha,
alpha^5=alpha^2+alpha+1,
alpha^6=alpha^2+1,
alpha^7=1.
```

따라서 `alpha`는 `F_8^×`의 생성원이고

```text
(alpha^2+alpha+1)^(-1)=alpha^2.
```

`F_9=F_3(i)`, `i^2=-1`에서 `1+i`의 위수는 `8`이다.

### 4.2 다항식 인수분해

다음을 `F_2[X]`에서 독립적으로 확인했다.

```text
X^4-X = X(X+1)(X^2+X+1),
X^8-X = X(X+1)(X^3+X+1)(X^3+X^2+1).
```

또한 `X^4+X+1`은 `F_2[X]`에서 기약이다.

### 4.3 기약다항식의 개수

모비우스 반전 공식으로 다음 값을 다시 계산했다.

```text
N_2(1)=2,
N_2(2)=1,
N_2(3)=2,
N_2(4)=3,
N_2(5)=6,
N_2(6)=9,
N_3(2)=3.
```

### 4.4 부분체와 자동동형

```text
F_{p^6} ∩ F_{p^10}=F_{p^2},
F_{p^6}F_{p^10}=F_{p^30}.
```

`F_{q^12}/F_q`에서 `sigma=Frob_q`라 하면

```text
Fix(<sigma^d>)=F_{q^d}  (d|12)
```

이며 부분군 포함과 고정체 포함의 방향이 반대임을 확인했다.
