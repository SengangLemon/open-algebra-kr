## 3. 주요 수정 사항

### 3.1 탑 법칙의 무한차수 논증 교정

초기 초고는 유한차수에서 기저 곱을 증명한 뒤, 무한차수의 경우를 “임의로 큰 유한 선형독립 집합”으로 처리했다. 이는 일반적인 무한 기수의 차원을 완전히 설명하지 못한다.

최종 원고에서는 `L/K`의 기저 `(x_i)_{i∈I}`와 `M/L`의 기저 `(y_j)_{j∈J}`를 직접 사용하여

```text
{x_i y_j : (i,j)∈I×J}
```

가 `M/K`의 기저임을 증명했다. 따라서 유한·무한차수 모두에 대해

```text
[M:K] = [M:L][L:K]
```

가 기수 곱의 의미로 성립한다.

### 3.2 프로베니우스의 비전사 예제 보강

`F_p(t)`에서 `t`가 `p`제곱이라고 가정하면

```text
1 + p deg(g) = p deg(f)
```

를 얻어 법 `p`에서 모순이 생기는 논증을 명시했다. 따라서 무한체에서는 프로베니우스가 단사여도 전사일 필요가 없음을 구체적으로 보였다.

### 3.3 단순확장의 체 구조 명확화

`α`가 대수적일 때

```text
K[X]/(m_{α,K}) ≅ K[α]
```

이고 최소다항식이 기약이므로 몫환이 체임을 사용해 `K[α]=K(α)`를 증명했다. 영이 아닌 `f(α)`의 역원을 베주 항등식으로 계산하는 방법도 별도로 설명했다.

### 3.4 네 원소 체의 문장 정밀화

`F_2(α)`에서 `α^2+α+1=0`일 때 “영이 아닌 원소들이 `α^3=1`을 만족한다”는 모호한 문장을 제거했다. 최종 원고는 영이 아닌 모든 원소 `x`가 `x^3=1`을 만족하며, 특히 `α^3=1`이라고 구분한다.

### 3.5 페이지 나눔과 참고문헌 중복 수정

- 단순확장 절의 학습목표 상자가 페이지 끝에서 비정상적으로 시작하지 않도록 절 시작 위치를 조정했다.
- `book` 클래스와 수동 `chapter*`가 함께 만들어 내던 참고문헌 제목 중복을 제거했다.
- 최종 참고문헌 페이지에는 한국어 제목 `참고문헌`이 한 번만 나타난다.

## 4. 독립 재계산 결과

다음 계산을 원고와 별도로 다시 확인했다.

### 4.1 세제곱근 확장

`α^3=2`일 때

```text
α^7 = 4α
(1+α)^(-1) = (1-α+α^2)/3
(1+α+α^2)^2 = 5+4α+3α^2
```

이다.

또한

```text
(2+α+α^2)(1-α^2/2)=1
```

이므로

```text
(2+α+α^2)^(-1)=1-α^2/2.
```

### 4.2 이차확장

```text
(3+2√2)^(-1)=3-2√2
(1+√2)^5=41+29√2
```

를 확인했다.

### 4.3 두 제곱근을 첨가한 확장

```text
[Q(√2,√3):Q]=4
```

이고

```text
1, √2, √3, √6
```

이 `Q`-기저임을 탑 법칙과 선형독립성으로 재검산했다.

`β=√2+√3`에 대해서는

```text
β^4-10β^2+1=0
Q(β)=Q(√2,√3)
```

이므로 최소다항식이

```text
X^4-10X^2+1
```

임을 확인했다.

### 4.4 여덟 원소 체

`α^3+α+1=0`인 `F_2(α)`에서

```text
α^3=α+1
α^(-1)=α^2+1
(α+1)^(-1)=α^2+α
α^7=1
```

을 직접 계산했다.

### 4.5 `X^3-2`의 분해체를 향한 확장

`α=∛2`, `ω^2+ω+1=0`, `ω≠1`일 때

```text
[Q(α):Q]=3
[Q(α,ω):Q(α)]=2
[Q(α,ω):Q]=6
```

이며

```text
1, α, α^2, ω, αω, α^2ω
```

가 `Q`-기저임을 확인했다.
