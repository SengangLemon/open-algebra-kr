## 3. 주요 검수·수정 사항

### 3.1 기약인수 정리의 중복도 표현 교정

기약다항식이 비분리인 경우 같은 기약인수가 거듭제곱 중복도로 나타날 수 있으므로, 정리를 다음 대상에 관한 명제로 명확히 했다.

```text
L[X]에서 나타나는 서로 다른 일계수 기약인수들의 집합
```

자동동형군은 이 서로 다른 인수들을 하나의 궤도로 순열하며, 모든 인수의 차수는 같다. 중복도는 별도로 유지된다.

### 3.2 분리폐포의 정규성 증명 추가

`L/K`가 정규일 때 `K_s/K`도 정규라는 사실을 단순히 인용하지 않고 다음과 같이 증명했다.

1. `K_s`의 임의의 `K`-매장을 `L`의 `K`-매장으로 연장한다.
2. `L/K`의 정규성으로 연장된 매장이 `L`을 보존한다.
3. 자동동형은 최소다항식과 분리성을 보존하므로 `K_s`를 자기 자신으로 보낸다.
4. 체매장 판정으로 `K_s/K`의 정규성을 얻는다.

### 3.3 합성체 차수 보조정리 추가

유한 정규 분리확장 `E/K`와 순수비분리확장 `P/K`에 대해

```text
[EP:P]=[E:K]
```

를 자동동형 제한 사상의 전단사로 증명했다. `P/K`의 순수비분리성 때문에 `E`의 모든 `K`-자동동형 연장이 `P`를 점별로 고정한다는 점을 사용한다. 이 보조정리로 `L=K_sK_i`의 차수 비교가 독립적으로 완결되었다.

### 3.4 무한 정규확장의 분해 보강

임의의 `a in L`에 대해 `K(a)/K`의 유한 정상폐포 `N`을 `L` 안에서 취하고, 유한한 경우의

```text
N=N_sN_i
```

를 적용했다. `N_s subset K_s`, `N_i subset K_i`를 확인하여 모든 `a`가 `K_sK_i`에 속함을 보였다.

### 3.5 조판 경고 제거

자동동형 궤도 절의 시작 위치를 새 페이지로 조정하여 `tcolorbox`의 빈 박스 경고를 제거했다. 최종 XeLaTeX 패스에는 원고 관련 경고가 남지 않는다.

## 4. 독립 재계산 결과

### 4.1 순삼차확장의 정상폐포

`alpha=cuberoot(2)`와 원시 삼차단위근 `omega`에 대해

```text
N=Q(alpha,omega)
```

는 `X^3-2`의 분해체이다. `Q(alpha)`는 실수체이고 `omega`는 비실수이므로

```text
[N:Q(alpha)]=2,
[N:Q]=6.
```

### 4.2 사차근의 정상폐포와 자동동형

`alpha=fourthroot(2)`에 대해

```text
N=Q(alpha,i)
```

는 `X^4-2`의 분해체이고

```text
[N:Q]=8.
```

자동동형은

```text
alpha -> i^k alpha  (k=0,1,2,3),
i     -> ±i
```

의 여덟 선택으로 주어진다. `alpha`의 궤도 크기는 `4`, 안정자 크기는 `2`이다.

### 4.3 오차 순수확장의 정상폐포

`alpha=fifthroot(2)`와 원시 오차단위근 `zeta_5`에 대해

```text
N=Q(alpha,zeta_5)
```

는 `X^5-2`의 분해체이다. 두 부분확장의 차수가 `5`와 `4`이고 교집합이 `Q`이므로

```text
[N:Q]=20.
```

### 4.4 중첩 제곱근의 정규 단순확장

```text
alpha=sqrt(2+sqrt(2))
```

에 대해

```text
m_alpha(X)=X^4-4X^2+2.
```

다른 양의 근 `beta=sqrt(2-sqrt(2))`는

```text
beta=sqrt(2)/alpha
```

이므로 `Q(alpha)`에 속한다. 네 근 `±alpha, ±beta`가 모두 체 안에 있어 확장은 정규이며, `alpha -> beta`인 자동동형의 위수는 `4`이다.

### 4.5 혼합 정규확장의 두 부분

`p`가 홀수이고

```text
K=F_p(s,t),
alpha^p=s,
beta^2=t,
L=K(alpha,beta)
```

일 때

```text
Aut_K(L)={id,tau},
tau(alpha)=alpha,
tau(beta)=-beta.
```

따라서

```text
K_i=K(alpha),
K_s=K(beta),
L=K_sK_i.
```

### 4.6 궤도-안정자 계산

`L=Q(sqrt(2),sqrt(3))`에서 자동동형군은 두 제곱근의 독립적인 부호 변화로 주어지는 위수 `4`의 군이다.

- `sqrt(2)+sqrt(3)`의 궤도 크기: `4`, 안정자 크기: `1`
- `sqrt(2)`의 궤도 크기: `2`, 안정자 크기: `2`

각 경우

```text
|orbit|=|G|/|stabilizer|
```

가 성립한다.
