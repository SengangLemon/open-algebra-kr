## 3. 주요 검수·수정 사항

### 3.1 자유모듈 기저 증명의 다항식환 단계 보강

초고의 귀납증명에서

```text
R[s_1,...,s_{n-1},T_n]
=R[s_1,...,s_{n-1}][T_n]
```

을 사용할 때 필요한 대수적 독립성 논증을 추가했다. 단항식

```text
s_1^{a_1}...s_{n-1}^{a_{n-1}}T_n^b
```

의 사전식 최고항 지수가 `(a_1,...,a_{n-1},b)`를 유일하게 결정함을 보여 서로 다른 단항식의 최고항이 상쇄되지 않도록 했다. 그 뒤 `s_n`을 `T_n`에 관한 일계수 `n`차다항식으로 보고 반복나눗셈 보조정리를 적용했다.

### 3.2 일반 가환환에서의 종결식 곱셈성 정밀화

실제 차수만으로 쓴 모호한 공식을 형식적 차수를 포함한 다음 공식으로 교정했다.

```text
Res_{m_1+m_2,n}(f_1f_2,g)
=Res_{m_1,n}(f_1,g)Res_{m_2,n}(f_2,g),

Res_{m,n_1+n_2}(f,g_1g_2)
=Res_{m,n_1}(f,g_1)Res_{m,n_2}(f,g_2).
```

보편 계수다항식환에서 최고차계수를 국소화하여 첫 다항식을 일계수로 만든 뒤 노름의 곱셈성을 적용하고, 얻어진 다항식 항등식을 임의의 가환환으로 특수화하도록 증명을 보강했다.

### 3.3 종결식의 곱셈성과 근 공식 사이의 순환논증 제거

초고의 일반 곱셈성 증명이 뒤에서 증명할 근 공식에 의존할 위험을 제거했다. 일계수의 경우는 몫환 곱셈사상의 행렬식으로 직접 증명하고, 일반 경우는 국소화와 특수화로 확장했다. 이후에만 일차인수에 대한 곱셈성을 사용하여 근 공식을 증명하도록 논리 순서를 고정했다.

### 3.4 희소다항식 판별식의 계산 완성

`f=X^m+aX+b`의 판별식 공식에서 생략되어 있던 근 곱 계산을 완성했다. `f'`의 근 `β_j`에 대해

```text
β_j^{m-1}=-a/m,

f(β_j)=((m-1)/m)aβ_j+b
```

를 사용하고 `X^{m-1}+a/m`에서의 평가곱을 직접 계산하여

```text
Res(f,f')=(1-m)^{m-1}a^m+m^m b^{m-1}
```

을 얻은 뒤 판별식 부호를 적용했다.

### 3.5 일반 환과 체의 공통근 서술 분리

두 일차식의 종결식 예제와 공통근 판정에서 일반 가환환과 체의 상황을 분리했다. 일반 환에서는 계수벡터의 비례나 종결식의 소멸만으로 공통근의 존재가 자동으로 따라오지 않음을 명시했고, 완전한 동치는 체 위에서 실제 차수를 사용할 때만 서술했다.

### 3.6 연습문제의 가정 보완

다음 조건을 문제에 명시했다.

- 반복나눗셈 문제에 `d≥1`
- 종결식 베주 문제에 형식적 차수 `m,n`
- 근 공식 문제에 분해환과 `n=deg g`

- 삼차 분해체 문제에 `f`가 일계수

## 4. 독립 재계산 결과

### 4.1 기본대칭식 항등식

다음 항등식을 직접 전개하여 확인했다.

```text
T_1^2+T_2^2+T_3^2=s_1^2-2s_2,

T_1^3+T_2^3+T_3^3=s_1^3-3s_1s_2+3s_3,

Σ_{i≠j}T_i^2T_j=s_1s_2-3s_3,

Σ_{i<j}T_i^2T_j^2=s_2^2-2s_1s_3.
```

### 4.2 삼차 판별식

```text
Disc(X^3+pX+q)=-4p^3-27q^2.
```

따라서

```text
Disc(X^3-X+1)=-23,
Disc(X^3-3X+1)=81.
```

첫 다항식의 갈루아군은 `S_3`, 둘째의 갈루아군은 `A_3≅C_3`임을 기약성과 함께 확인했다.

### 4.3 일반 삼차식

```text
Disc(X^3+aX^2+bX+c)
=a^2b^2-4b^3-4a^3c-27c^2+18abc.
```

평행이동으로 우울형 삼차식에 줄인 계산과 실베스터 행렬식 계산이 일치함을 확인했다.

### 4.4 특별한 사차식

```text
Disc(X^4+aX^2+bX+c)
=256c^3-128a^2c^2+144ab^2c-27b^4
 +16a^4c-4a^3b^2.
```

상징적 행렬식 계산으로 공식을 재검산했다. 또한

```text
Disc(X^4-2)=-2048.
```

### 4.5 곱의 판별식

```text
f=(X^2-2)(X^2-3)
```

에 대해

```text
Disc(X^2-2)=8,
Disc(X^2-3)=12,
Res(X^2-2,X^2-3)=1
```

이므로

```text
Disc(f)=8·12·1^2=96.
```

네 근을 직접 사용한 계산과 일치한다.

### 4.6 두 이차식의 종결식

형식적 차수 `(2,2)`인

```text
f=a_0X^2+a_1X+a_2,
g=b_0X^2+b_1X+b_2
```

에 대해 실베스터 행렬식을 독립적으로 전개하여

```text
Res_{2,2}(f,g)
=(a_0b_2-a_2b_0)^2
 +(a_1b_2-a_2b_1)(a_1b_0-a_0b_1)
```

을 확인했다.
