# Open Algebra KR

**갈루아 이론으로 배우는 현대대수학**

한국어권 독학자와 대학 학부생을 위한 오픈 현대대수학 교재 프로젝트입니다. 군, 환, 다항식, 체확장, 갈루아 이론을 하나의 흐름으로 연결하고, 각 개념을 동기·직관·예제·엄밀한 증명·연습문제·해설의 순서로 설명합니다.

> Status: Early draft / 집필 초기 단계

## 목표

- 갈루아 이론의 관점에서 현대대수학의 전체 흐름 설명
- 정의 이전에 동기와 직관 제시
- 증명 아이디어와 엄밀한 증명 분리
- 난이도별 예제와 연습문제 제공
- LaTeX 기반 PDF와 웹 버전 동시 관리
- 공개 이슈와 릴리스를 통한 지속적인 교정

## Volume 1

1. 방정식에서 현대대수학까지
2. 군과 대칭
3. 부분군과 생성
4. 잉여류와 라그랑주 정리
5. 정규부분군과 몫군
6. 군 준동형과 동형정리
7. 환과 아이디얼
8. 다항식환과 나눗셈 알고리즘
9. 인수분해와 기약성

## 저장소 구조

```text
book/        교재 LaTeX 원고
workbook/    연습문제와 해설
notes/       표기법·용어·편집 지침
anki/        복습 카드 자료
.github/     자동 빌드와 기여 양식
```

## 빌드

TeX Live와 `latexmk`가 설치된 환경에서 다음 명령을 실행합니다.

```bash
cd book
latexmk -xelatex main.tex
```

## 저작 원칙

이 프로젝트는 특정 교재의 번역본이 아닙니다. 여러 표준 참고문헌에서 학문적 구조를 연구하되, 설명·예제·연습문제·도식은 독창적으로 집필합니다. 외부 자료를 직접 인용하거나 변형할 때에는 출처와 라이선스를 명시합니다.
