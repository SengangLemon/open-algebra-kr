# Open Algebra KR

**갈루아 이론으로 배우는 현대대수학**

한국어권 독학자와 대학 학부생을 위한 오픈 현대대수학 교재 프로젝트입니다. 군, 환, 다항식, 체확장, 갈루아 이론을 하나의 흐름으로 연결하고, 각 개념을 동기·직관·예제·엄밀한 증명·연습문제·해설의 순서로 설명합니다.

> **Status: Volume 1 Draft 0.3 검수 완료 · Volume 2 Draft 0.6 전권 초고 완료 · Volume 3 Draft 0.6 집필 중**

Volume 1은 군론·환론·다항식론의 첫 수학·통합 검수 패스를 마쳤습니다. Volume 2는 표수와 최소다항식에서 유한 갈루아 대응까지 이어지는 전권 초고를 완성했습니다. Volume 3에서는 방정식의 갈루아군, 대칭다항식, 판별식·종결식, 사차·오차다항식의 구체적 군 계산, 원분체와 순환확장, 노름·대각합과 캐릭터의 선형독립, 근호확장과 가해군을 전개합니다. 모든 권은 아직 정식 출판본이 아니며 외부 수학 검토와 문장·디자인 교정이 남아 있습니다.

## 현재 범위

### Volume 1 — 군, 환, 다항식

- 방정식에서 현대대수학까지
- 군과 대칭
- 환과 아이디얼
- 다항식과 인수분해
- 난이도별 연습문제와 선별 상세 풀이
- 기호 목록과 한국어–영어 용어 대조표

### Volume 2 — 대수적 체확장

- 표수·소체·프로베니우스 준동형
- 체확장의 차수, 대수적 원소와 최소다항식
- 근의 첨가, 분해체와 대수적 폐포
- 분리성과 순수비분리 확장
- 유한체와 상대 프로베니우스
- 정규확장, 켤레원소와 정상폐포
- 갈루아 확장과 근의 순열
- 아르틴 고정체 정리
- 유한 갈루아 대응, 정규부분군과 몫군
- A/B/C 난이도별 연습문제와 선별 상세 풀이

### Volume 3 — 갈루아 이론과 방정식

- 다항식의 갈루아군과 대칭군 안의 순열표현
- 기약성과 근 집합 작용의 추이성
- 기약인수와 갈루아 궤도의 대응
- 이차·삼차다항식의 갈루아군 계산
- 삼차 판별식에 의한 $C_3/S_3$ 판정
- 일반 $n$차방정식과 전체 대칭군
- 일반 가환환 위의 기본대칭식 정리
- 사전식 최고항 제거와 대칭다항식 계산
- 판별식의 보편 정의와 교대군 판정
- 실베스터 행렬과 종결식
- 베주 항등식·공통근·노름에 의한 종결식 해석
- 판별식과 도함수 종결식의 관계
- 세 쌍분할과 사차식의 삼차분해식
- $V_4,C_4,D_4,A_4,S_4$의 완전한 사차 판정
- 좋은 소수의 프로베니우스 순환형
- $C_5,D_5,F_{20},A_5,S_5$의 오차 갈루아군 분류
- 일반 부분군 분해식과 $D_5$-분해식
- 사차·오차 각 다섯 군의 구체적 계산 예제
- 단위근·오일러 함수와 원분다항식
- 원분다항식의 $\Q$ 위 기약성
- 원분체의 갈루아군 $(\Z/n\Z)^\times$
- 최대 실부분체와 원분체의 중간체 계산
- 유한체 위 원분다항식과 상대 프로베니우스
- 곱셈형·가법형 힐베르트 정리 90
- 단위근을 포함하는 기준체 위 순환 근호확장
- 아르틴--슈라이어 확장과 유한 Kummer 쌍
- 곱셈사상에 의한 체확장의 노름과 대각합
- 최소다항식·체매장·중간체 탑을 이용한 노름과 대각합 계산
- 아르틴의 캐릭터 및 체매장 선형독립 정리
- 분리차수·비분리차수와 켤레들의 합·곱 공식
- 대각합 쌍, 분리성 판정과 쌍대기저
- 유한체의 노름·대각합과 노름 방정식
- 교환자부분군, 도함열과 가해군
- 유한 가해군의 소수차 순환 정규열
- 단위근·순수근호·아르틴--슈라이어 근으로 이루어진 근호탑
- 갈루아군의 가해성과 근호해법의 동치
- 소수차 가해 추이군과 실근을 이용한 비가해성 판정
- Cardano 공식과 사차공식의 갈루아군 정규열 해석
- A/B/C 난이도별 연습문제와 선별 상세 풀이

각 권의 계획과 상태는 [`notes/roadmaps/`](notes/roadmaps/)에 기록합니다. 장별 수학 검수 기록은 [`notes/qa/`](notes/qa/)에, Volume 1 전체 품질 상태는 [`notes/quality-assurance.md`](notes/quality-assurance.md)에 있습니다.

## 빌드

TeX Live와 `latexmk`가 설치된 환경에서 다음 명령을 실행합니다.

```bash
# Volume 1
cd book
latexmk -xelatex main.tex

# Volume 2
cd ../volume2
latexmk -xelatex main.tex

# Volume 3
cd ../volume3
latexmk -xelatex main.tex
```

Pull request에서는 GitHub Actions가 Volume 1·2·3을 각각 컴파일하고 별도의 PDF artifact를 생성합니다.
